# FEC Scope & Boundaries v2.3

## FEC 负责

- Contact qualification；
- G/E/A/C 语义；
- topology / equivalence / local coordination；
- Evidence provenance / provider identity / lineage audit；
- modality availability contract；
- Context 与 Reference compatibility；
- U / D_cal normal-memory admission；
- Reference Bundle lifecycle + persistence；
- calibration validity / support / abstention；
- optional genuine class-evidence calibration/fusion extension；
- selected-classifier score pack 的独立 labeled calibration / prediction-set bridge（v2.3，Extension/Control Plane）。

## FEC 不负责

- 自动发现所有设备机理/Contact；
- 把 observational/inductive/learning bias 当三份 Evidence；
- 把 shared lineage 自动变成 equivalence；
- 把 scalar anomaly E 转成 class belief；
- 通用根因分类、RUL、maintenance optimization、novel fault；
- 无资格时强行修 drift/missingness/Sim2Real gap。

## 科研主张边界

conformal、Mondrian、weighted/localized calibration、belief fusion、evidential heads、missing-modality fusion、virtual sensing、Sim2Real 和 physics-informed learning 都有成熟 prior art。FEC 对这些方法的策略是 assimilate-as-components/contracts，不宣称方法本身由 FEC 首创。

FEC 当前工程身份仍是：

> 保持 Evidence 的存在、适用、异常性、来源、上下文、参考有效性、写权限和健康依赖不被过早压成一个分数，并把这些状态放入可生产管理的生命周期。
