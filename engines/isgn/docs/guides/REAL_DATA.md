# Guide: Applying ISGN to a new real system

1. Describe measured states, inputs, contexts, sampling and sensor metadata.
2. Define only the mechanism knowledge you actually know.
3. Start with a local mechanism scope if the whole system is not dynamically closed.
4. Run observation qualification before derivative-based discovery.
5. Use at least one mature discovery backend and, when possible, an independent backend for structural confirmation.
6. Recover missing terms/edges/constitutive relations.
7. Calibrate normal residual floors independently of the candidate model.
8. Certify or refuse.
9. Record unsupported cases as application issues; do not add a device-specific primitive to Core merely to make one dataset pass.
