# CLI reference: core commands

```text
doctor                     environment/backend status
reduce-physics             physics-aware pre-discovery algebraic search reduction
recover-missing            fixed partial physics -> derivative-residual missing term(s)
recover-missing-trajectory fixed partial physics -> trajectory residual -> symbolic distillation
recover                    graph recovery
complete                   partial graph completion
consensus                  independent backend structure comparison
calibrate-coverage         normal measurement/numerical floor
certify                    completion/refusal certificate
symbolic-export            prepare a relation task for external symbolic discovery
symmatika-run               optional external SymMatika bridge
```

Auxiliary commands for Observation, PHM, Atlas, architecture compilation and closed-loop planning remain supported but are not the core research claim of Toolkit 2.1.
